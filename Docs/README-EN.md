# YSM-Model-Author

- A collection of YSM models organized by author.

## Notes

- Folder Naming Convention

```
<English Work Name>_<English Character Name>_<Chinese Character Name>_<Personal Rating>
Personal Rating: LA, LB, LC, LD
```

- Usage Notes
  - The suffixes LA, LB, LC, LD are personal rating indicators (for production quality / completion level) and carry no other meaning.
  - The archive contains project source files, while `.ysm` are encrypted model files.
  - This repository contains some **18+** models. Please use them at your own discretion. I have not marked all R18 models with the `nsfw` tag.
  - Do **not** sell any models from this repository in any form. You will be held responsible for all consequences.
- Model Notes
  - If you encounter any non‑functional models, please let me know via Issue. Thank you.
- Other Notes
  - I am not very familiar with GitHub. If you wish to modify any content, please notify me via Issue, or you may clone this repository and make changes on your own.
